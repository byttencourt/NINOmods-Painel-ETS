
================================================================================
🚀 GUIA DE INSTALAÇÃO - PAINEL ETS2 (DEBIAN 13 / PROXMOX / MIKROTIK)
================================================================================

Este guia foca em fazer o painel funcionar na porta 8081 acessível externamente.

--------------------------------------------------------------------------------
0. OBTENDO OS ARQUIVOS NO DEBIAN
--------------------------------------------------------------------------------
Se você ainda não tem os arquivos no seu servidor Debian, siga estes passos:

1. Atualize o sistema e instale o Git:
   apt update && apt install git -y

2. Clone o repositório oficial:
   git clone https://github.com/byttencourt/NINOmods-Painel-ETS.git

3. Entre na pasta do projeto:
   cd NINOmods-Painel-ETS

--------------------------------------------------------------------------------
1. PREPARAÇÃO DO "INDEX" (FRONTEND)
--------------------------------------------------------------------------------
No seu computador (VS Code), você precisa gerar a pasta 'dist' que contém o site:
1. `npm install`
2. `npm run build`
3. Envie a pasta 'dist' gerada para o Debian no caminho: /var/www/html/ets2-panel/

No Debian, verifique se os arquivos estão lá:
`ls -la /var/www/html/ets2-panel/` (Deve aparecer index.html e pastas assets)

--------------------------------------------------------------------------------
2. CONFIGURAÇÃO DO NGINX (PORTA 8081)
--------------------------------------------------------------------------------
O Nginx servirá o site e a API na mesma porta (8081).
`nano /etc/nginx/sites-available/ets2-panel`

COLE ESTE CONTEÚDO:
server {
    listen 8081;
    server_name _;

    root /var/www/html/ets2-panel;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Encaminha chamadas de /api para o backend na porta 3000
    location /api/ {
        proxy_pass http://localhost:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

# Ativa e reinicia
ln -s /etc/nginx/sites-available/ets2-panel /etc/nginx/sites-enabled/
nginx -t && systemctl restart nginx

# Abre a porta no Firewall do Debian (se tiver ufw)
ufw allow 8081/tcp

--------------------------------------------------------------------------------
3. CONFIGURAÇÃO NO MIKROTIK (ACESSO EXTERNO)
--------------------------------------------------------------------------------
Você precisa dizer ao Mikrotik que quem vier de fora na porta 8081 deve ir para sua VM.

Abra o terminal do Mikrotik (WinBox > New Terminal) e cole (AJUSTE O IP):
/ip firewall nat add action=dst-nat chain=dstnat dst-port=8081 protocol=tcp to-addresses=IP_DA_SUA_VM_DEBIAN to-ports=8081

--------------------------------------------------------------------------------
4. VERIFICAÇÃO DE STATUS
--------------------------------------------------------------------------------
1. Backend rodando? `systemctl status ets2-backend` (Porta 3000)
2. Nginx rodando? `systemctl status nginx` (Porta 8081)
3. Teste Local: No Debian, digite `curl http://localhost:8081` (Deve vir código HTML)
4. Teste Externo: No navegador do seu PC, digite `http://IP_DO_MIKROTIK:8081`

DICA: Se o backend estiver funcional apenas via tunnel, verifique se o 'server.js'
está ouvindo em '0.0.0.0' e não apenas em '127.0.0.1'.
